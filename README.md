# Устное собеседование по русскому языку (9 класс)

Веб-приложение для подготовки к устному собеседованию по русскому языку с автоматической проверкой ответов через Google Gemini AI.

## Возможности

-  **Чтение текста вслух** - проверка выразительности и правильности произношения
-  **Пересказ текста** - оценка сохранения микротем и использования приёмов сжатия
-  **Монолог на заданную тему** - проверка соответствия теме и речевой связности
-  **Автоматическая проверка через Google Gemini AI** - объективная оценка по критериям ФИПИ
-  **Детальная обратная связь** - разбор ошибок и рекомендации по улучшению
-  **Оценка по критериям ФИПИ** - точное соответствие требованиям экзамена

## Быстрый старт

### 1. Запуск на Windows (локальный Python, без установки)

На Windows **ничего дополнительно устанавливать не нужно**: проект использует локальный переносимый Python из папки `python_portable` и **не зависит от `PATH` системы**.

```bat
:: В корне проекта
start.bat
```

Скрипт `start.bat`:
- **скачивает и разворачивает локальный Python** в папку `python_portable` (если его ещё нет);
- **устанавливает зависимости** из `requirements.txt` в этот локальный интерпретатор;
- **запускает сервер** командой `run_server.py` через локальный `python.exe` из `python_portable`.

### 1b. Ручная установка (Linux/Mac или продвинутый сценарий)

Если вы запускаете проект не на Windows, можно использовать обычное виртуальное окружение:

```bash
# Клонируйте репозиторий
git clone <repository-url>
cd rus-oral-exam-ai

# Создайте виртуальное окружение
python -m venv venv

# Активируйте виртуальное окружение
# Windows:
venv\Scripts\activate
# Linux/Mac:
source venv/bin/activate

# Установите зависимости
pip install -r requirements.txt
```

### 2. Настройка API ключа

1. Получите бесплатный API ключ Google Gemini:
   - Перейдите на [Google AI Studio](https://aistudio.google.com/app/apikey)
   - Создайте новый API ключ (бесплатно)

2. Создайте файл `backend/conf.env`:
```env
GEMINI_API_KEY=ваш_ключ_здесь
HOST=127.0.0.1
PORT=8000
```

### 3. Запуск

#### Windows (рекомендуется)

```bat
start.bat
```

#### Linux/Mac или ручной запуск

```bash
# Запустите сервер
python run_server.py

# Или используйте uvicorn напрямую
python -m uvicorn backend.main:app --reload
```

Откройте браузер и перейдите по адресу: **http://127.0.0.1:8000**

## Использование

1. **Выберите тип задания:**
   - Чтение текста
   - Пересказ текста
   - Монолог

2. **Прочитайте задание и инструкции**

3. **Введите ваш ответ** в текстовое поле (или подготовьте устный ответ)

4. **Нажмите "Проверить ответ"**

5. **Получите результат:**
   - Оценку по критериям ФИПИ
   - Детальную обратную связь
   - Рекомендации по улучшению

**Используемая модель по умолчанию:** `gemini-1.5-flash` (быстрая, мультимодальная, поддерживает аудио и текст)

## 🔧 Технологии

- **Backend:** FastAPI, Python 3.11+
- **AI:** Google Gemini API  
  - модель по умолчанию: `gemini-1.5-flash` (поддерживает аудио-вход и подходит для анализа устной речи)  
  - при необходимости можно задать другую модель через переменную `GEMINI_MODEL` (например, аудио‑ориентированные варианты линейки Gemini 2.5, если они доступны вашему ключу)
- **Frontend:** HTML, CSS, JavaScript (vanilla)
- **Server:** Uvicorn

## 📝 Примечания

- **Без API ключа** приложение работает в режиме моковой проверки (примерная оценка)
- **Для полной функциональности** требуется валидный Google Gemini API ключ
- Конкретная модель берётся из переменной окружения `GEMINI_MODEL`, при её отсутствии используется `gemini-1.5-flash`
- Рекомендуется выбирать только стабильные, поддерживаемые модели (см. документацию Gemini для актуального списка)

## 🐛 Решение проблем

### Ошибка 400 (User location is not supported for the API use)
- Включите VPN на страны, в которых Gemini [поддерживается](https://ai.google.dev/gemini-api/docs/available-regions)

### Ошибка 429 (Превышен лимит)
- Подождите ~30 секунд и попробуйте снова
- Проверьте, не превысили ли лимит 15 запросов в минуту
- Проверьте дневной лимит (1500 запросов в день)

### API ключ не загружается
- Убедитесь, что файл `backend/conf.env` существует
- Проверьте, что ключ начинается с правильного формата
- Убедитесь, что файл сохранён в кодировке UTF-8 без BOM

### Модель не найдена (404)
- Проверьте, что значение `GEMINI_MODEL` соответствует реальному имени модели из документации Gemini
- При отсутствии переменной `GEMINI_MODEL` приложение использует `gemini-1.5-flash`
