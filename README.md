# Устное собеседование по русскому языку (9 класс)

Веб-приложение для подготовки к устному собеседованию по русскому языку с автоматической проверкой ответов через Google Gemini AI.

## Возможности

-  **Чтение текста вслух** - проверка выразительности и правильности произношения
-  **Пересказ текста** - оценка сохранения микротем и использования приёмов сжатия
-  **Монолог на заданную тему** - проверка соответствия теме и речевой связности
-  **Автоматическая проверка через Google Gemini AI** - объективная оценка по критериям ФИПИ
-  **Детальная обратная связь** - разбор ошибок и рекомендации по улучшению
-  **Оценка по критериям ФИПИ** - точное соответствие требованиям экзамена

## Быстрый старт

### 1. Установка зависимостей

```bash
# Клонируйте репозиторий
git clone <repository-url>
cd rus-oral-exam-ai

# Создайте виртуальное окружение
python -m venv venv

# Активируйте виртуальное окружение
# Windows:
venv\Scripts\activate
# Linux/Mac:
source venv/bin/activate

# Установите зависимости
pip install -r requirements.txt
```

### 2. Настройка API ключа

1. Получите бесплатный API ключ Google Gemini:
   - Перейдите на [Google AI Studio](https://aistudio.google.com/app/apikey)
   - Создайте новый API ключ (бесплатно)

2. Создайте файл `backend/conf.env`:
```env
GEMINI_API_KEY=ваш_ключ_здесь
HOST=127.0.0.1
PORT=8000
```

### 3. Запуск

```bash
# Запустите сервер
python run_server.py

# Или используйте uvicorn напрямую
python -m uvicorn backend.main:app --reload
```

Откройте браузер и перейдите по адресу: **http://127.0.0.1:8000**

## Использование

1. **Выберите тип задания:**
   - Чтение текста
   - Пересказ текста
   - Монолог

2. **Прочитайте задание и инструкции**

3. **Введите ваш ответ** в текстовое поле (или подготовьте устный ответ)

4. **Нажмите "Проверить ответ"**

5. **Получите результат:**
   - Оценку по критериям ФИПИ
   - Детальную обратную связь
   - Рекомендации по улучшению

**Используемая модель:** `gemini-1.5-flash` (быстрая и бесплатная)

## 📝 Примечания

- **Без API ключа** приложение работает в режиме моковой проверки (примерная оценка)
- **Для полной функциональности** требуется валидный Google Gemini API ключ
- Приложение автоматически выбирает доступную модель из списка стабильных
- Экспериментальные модели исключаются (имеют лимит 0 на бесплатном тарифе)

## 🐛 Решение проблем

### Ошибка 400 (User location is not supported for the API use)
- Включите VPN на страны, в которых Gemini [поддерживается](https://ai.google.dev/gemini-api/docs/available-regions)

### Ошибка 429 (Превышен лимит)
- Подождите ~30 секунд и попробуйте снова
- Проверьте, не превысили ли лимит 15 запросов в минуту
- Проверьте дневной лимит (1500 запросов в день)

### API ключ не загружается
- Убедитесь, что файл `backend/conf.env` существует
- Проверьте, что ключ начинается с правильного формата
- Убедитесь, что файл сохранён в кодировке UTF-8 без BOM

### Модель не найдена (404)
- Приложение автоматически выбирает доступную модель
- Убедитесь, что у вас есть доступ к Google Gemini API
